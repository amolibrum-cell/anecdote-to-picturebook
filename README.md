# anecdote-to-picturebook

짧은 일화(anecdote)를 그림책(picture book)으로 바꿔 주는 프로젝트입니다.

## 이 저장소의 용도

일상에서 겪은 에피소드, 가족이나 아이와의 추억, 짧은 경험담 같은 이야기를 입력하면, 이를 여러 장면으로 나누고 장면마다 그림과 글을 붙여 한 권의 그림책으로 만드는 것을 목표로 합니다.

## 기본 흐름

1. **일화 입력**: 몇 문장에서 몇 문단 정도의 짧은 이야기를 입력합니다.
2. **이야기 구성**: 일화를 그림책에 맞게 다듬고 페이지(장면) 단위로 나눕니다.
3. **장면별 글 작성**: 각 페이지에 들어갈 짧고 읽기 쉬운 문장을 만듭니다.
4. **삽화 생성**: 장면마다 어울리는 그림을 만들고, 등장인물과 화풍이 책 전체에서 일관되게 유지되도록 합니다.
5. **그림책 완성**: 글과 그림을 합쳐 읽거나 공유할 수 있는 형태로 출력합니다.

## 현재 상태

초기 단계 프로젝트로, 아직 구현 코드는 없습니다. 구조와 사용법은 개발이 진행되면 이 문서에 추가하겠습니다.
