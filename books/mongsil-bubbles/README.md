# 몽실몽실 비눗방울

유치원 친구 셋(나리, 솔이, 다홍)이 가을 공원에서 우연히 만나 비눗방울을 불며 노는 하루를 담은 그림책 더미(시안)입니다. 표지와 15쪽으로 되어 있습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 시안 페이지입니다. 브라우저로 열면 넘겨 보기, 한눈에 보기, 등장인물 탭이 있습니다. 그림은 모두 이 파일 안의 코드로 그립니다. |
| `storyboard-one-sheet.pdf` | 전체 흐름을 A4 가로 한 장(3×3)에 담았습니다. |
| `storyboard-large.pdf` | 펼친 두 쪽씩 A4 가로 9장에 담았고, 장마다 구성 메모가 있습니다. |
| `render-pdf.mjs` | `index.html`로 위의 PDF 두 개를 다시 만드는 스크립트입니다. |

온라인 시안: https://claude.ai/artifact/9qsXQj26FtqRNMBXYFJB9u

## 쪽 구성

책을 펼치면 왼쪽은 짝수 쪽, 오른쪽은 홀수 쪽입니다. 그래서 두 쪽을 한 그림으로 쓰는 펼침면은 6–7쪽, 12–13쪽에 둡니다.

| 펼친 면 | 왼쪽 | 오른쪽 |
|---|---|---|
| 표지 | 뒤표지 | 앞표지: 세 친구와 비눗방울 |
| 1쪽 | 면지 | 나리와 아빠가 가을 공원에 도착 |
| 2–3쪽 | 친구들과 우연히 만남 | 솔이 엄마의 “짜잔!” 비눗방울 세 개 |
| 4–5쪽 | 셋이 함께 후— | 솔이의 가을 도시락 |
| 6–7쪽 | 비눗방울 알사탕 제조법 (펼침면) | |
| 8–9쪽 | 나리 엄마 합류 | “저기 그네다!” |
| 10–11쪽 | 밀고, 타고, 불고 | “잡았다!” |
| 12–13쪽 | 파란 가을 하늘로 몽실몽실 (펼침면, 절정) | |
| 14–15쪽 | 하품이 옮아감, “우리 이제 집에 가자.” | “내일 유치원에서 또 만나!” 끝 |

6–7쪽은 백희나 작가의 『알사탕 제조법』에서 ‘만드는 순서’를 보여 주는 형식만 빌렸고, 글과 그림은 새로 썼습니다.

## 고칠 때

글과 장면은 `index.html` 안의 `S`(장면별 그림과 글)와 `rows`(펼친 면 순서와 구성 메모)에 있습니다. 고친 뒤 PDF를 다시 만들려면 이 폴더에서 아래처럼 실행합니다. Playwright가 필요합니다.

```sh
node render-pdf.mjs
```

손글씨 글꼴을 내려받아 `fonts/abs.css`로 두면 인터넷 연결 없이 그 글꼴로 만듭니다. `fonts/`는 저장소에 올리지 않습니다.
